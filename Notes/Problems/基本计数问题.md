# 基本计数问题

这里我更倾向于放一些比较"本原"一些的计数问题，它可能在各个地方被用到

## P1
同余方程$$ax \equiv 0 \pmod n$$在$[0,n - 1]$上的解有多少个？

设$g = \gcd(a,n)， a = a'g, n = n'g$
那么 
$$ax \equiv 0 \pmod n \Leftrightarrow n \mid ax \\ \Leftrightarrow n'g \mid a'gx \\\Leftrightarrow n' | a'x \\\Leftrightarrow n' | x$$
此时$x$的取值有：
$$0, \frac{n}{g}, \frac{2n}{g}, ..., \frac{(g - 1)n}{g}$$
一共$g$个
故结果为$\gcd(a, n)$

## P2
值域为$[1, n]$， 总和为$m$, 共 $t$ 个元素的序列有多少个？

使用生成函数描述答案：
$$\begin{align*}
    ans &= [x^m] ( x \frac{1 - x^n}{1 - x})^t \\
    &= [x^{m - t}]  (1 - x^n)^t (1 - x)^{-t} \\
    &= \sum_{i = 0}^ {\min(t, \frac{m - t}{n})} (-1)^t\binom{t}{i} \binom{-t}{m - t - in}\\
    &= \sum_{i = 0}^ {\min(t, \frac{m - t}{n})} (-1)^t\binom{t}{i} \binom{m - in - 1}{t - 1}
\end{align*}$$

预处理完组合数可以$O(\frac{m}{n})$地计算

## P2 Ex
值域为$[1, n]$， 总和为$m$, 序列有多少个？ 这里去掉了$t$个元素的限制
同样写出生成函数：
$$a_m = [x^m]\frac{1 - x}{1 - 2x + x^{n + 1}}$$
针对不同大小的$n, m$，有不同的求解方法
1. 写成递推
$$(1 - 2x + x^{n+1})A(x) = 1 - x$$
取第$m > n$项系数，有：
$$a_m - 2a_{m - 1} + a_{m - n - 1} = 0$$
即
$$a_m = 2a_{m - 1} - a_{m - n - 1}$$ 
且有初值：$a_0 = 1, a_m = 2^{m - 1} (1 \leq m \leq n)$

2. 稀疏有理式展开
$$A(x) = \frac{1 - x}{1 - 2x + x^{n + 1}}= (1 - x) \frac{1}{1 - 2x} \frac{1}{1 + \frac{x^{n + 1}}{1 - 2x}}$$
先不管$1 - x$,把后面那项展开：
$$F(x) = \frac{1}{1 - 2x}\frac{1}{1 + \frac{x^{n + 1}}{1 - 2x}} = \sum_{j \geq 0} (-1)^j (1 - 2x)^{-j-1} x^{j(n + 1)}$$ (这个变换技巧比较变态)
于是取第$m$项系数
$$[x^m]F(x) = \sum_{j=0}^{\lfloor m/(n+1) \rfloor} (-1)^j 2^{m-j(n+1)} \binom{m-jn}{j}$$
这个计算是$O(\frac{m}{n})$的
最后$A(x) = (1 - x)F(x)$， 因此$a_m = f_m - f_{m - 1}$

3. Bostan-Mori
调用Bostan-Mori计算即可，复杂度$O(n \log n \log m)$， 在$n$不大但是$m$非常大时适用
