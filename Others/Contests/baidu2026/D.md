可以做到 \(O(n^2)\)，而且不必套 Knuth。这里有一个更强的“二阶区间递推”。

先注意边权可改写成

\[
w(u,v)=\sum_{1\le i\le j\le n}
A_{i,j}\,[\, [i\le u\le j]\oplus[i\le v\le j]\,].
\]

即每个 \(A_{i,j}\) 表示区间 \([i,j]\) 的割：仅当 \(u,v\) 恰有一个落在该区间中时产生贡献。

因此对于 \(a<b<c<d\)，实际上同时成立

\[
\begin{aligned}
w(a,d)+w(b,c)&\le w(a,c)+w(b,d),\\
w(a,b)+w(c,d)&\le w(a,c)+w(b,d).
\end{aligned}
\]

这是 Kalmanson 型权值。右侧的交叉匹配 \((a,c),(b,d)\) 不优于两种消交方案，所以一定存在不交叉的最优匹配。

令 \(F_{l,r}\) 表示连续点 \(l,\dots,r\) 的最小匹配代价，其中 \(r-l+1\) 为偶数。常规转移是

\[
F_{l,r}=
\min_{\substack{l<k\le r\\k-l\text{ 为奇数}}}
\bigl(w(l,k)+F_{l+1,k-1}+F_{k+1,r}\bigr).
\]

关键是它可以化成

\[
\boxed{
F_{l,r}=
\min\left\{
w(l,r)+F_{l+1,r-1},\quad
F_{l,r-2}+F_{l+2,r}-F_{l+2,r-2}
\right\}.}
\tag{1}
\]

其中：

- 第一项对应直接匹配 \((l,r)\)；
- 第二项对应 \(l,r\) 分属两个不同外层弧。

证明核心是“隐藏弧稳定性”：在一个最优不交叉匹配中，被其他弧严格包含的匹配边，在区间两侧加入新点后，可以选取一个仍保留这些隐藏弧的最优解。证明就是连续使用

\[
(a,c),(b,d)\longrightarrow(a,d),(b,c)
\]

消交。

具体地，把 \([l,r-2]\) 与 \([l+2,r]\) 的最优解沿公共部分 \([l+2,r-2]\) 拼接：

- 若两侧外层弧不交叉，公共部分恰好被计算两次，所以代价是
  \[
  F_{l,r-2}+F_{l+2,r}-F_{l+2,r-2}.
  \]
- 若拼接后外层弧交叉，消交后会得到一个包含 \((l,r)\) 的匹配，且代价不增，因此这种情况不会优于第一项。

这就是式 (1)。同型的二阶递推也见 [Delon–Salomon–Sobolevski, Theorem 6](https://arxiv.org/abs/1102.1558)。

初始化和枚举：

```cpp
for (int l = 1; l < n; ++l)
    f[l][l + 1] = w(l, l + 1);

for (int len = 4; len <= n; len += 2) {
    for (int l = 1; l + len - 1 <= n; ++l) {
        int r = l + len - 1;
        f[l][r] = min(
            w(l, r) + f[l + 1][r - 1],
            f[l][r - 2] + f[l + 2][r] - f[l + 2][r - 2]
        );
    }
}
```

约定空区间 \(F_{x,x-1}=0\)。答案是 \(F_{1,n}\)。

边权也能用二维前缀和 \(P(x,y)=\sum_{i\le x,j\le y}A_{i,j}\) 在 \(O(1)\) 求出：

\[
\begin{aligned}
w(u,v)
={}&P(u,v-1)-P(u,u-1)\\
&+P(v,n)-P(u,n)-P(v,v-1)+P(u,v-1).
\end{aligned}
\]

所以总复杂度：

\[
\boxed{O(n^2)\text{ 时间， }O(n^2)\text{ 空间}}
\]

而输入本身已有 \(\Theta(n^2)\) 个数，这已经是渐进最优。

至于决策单调性：固定 \(l\) 时，可以选取最优解使 \(l\) 的匹配对象随 \(r\) 增大而不向左移动；但通常的双边 Knuth 界并不成立。例如仅令

\[
A_{1,4}=1,\qquad A_{2,5}=2
\]

其余为 \(0\)，则自然 DP 中

\[
\operatorname{opt}(1,6)=6,\qquad
\operatorname{opt}(3,6)=4,
\]

违反 Knuth 所需的 \(\operatorname{opt}(1,6)\le\operatorname{opt}(3,6)\)。因此这里真正有用的不是标准决策单调性，而是上面的二阶递推。

## 1. 为什么有两种消交方式

把边权写成

\[
w(u,v)=\sum_{1\le x\le y\le n}
A_{x,y}\left|
[\,u\in[x,y]\,]-[\,v\in[x,y]\,]
\right|.
\]

固定一个区间 \([x,y]\)，四个点 \(a<b<c<d\) 在这个区间中的 \(0/1\) 状态只能形如

\[
0\cdots 0\,1\cdots1\,0\cdots0.
\]

于是交叉配对 \((a,c),(b,d)\) 分割这个区间的次数，不少于另外两种配对。因此

\[
\begin{aligned}
w(a,b)+w(c,d)&\le w(a,c)+w(b,d),\\
w(a,d)+w(b,c)&\le w(a,c)+w(b,d).
\end{aligned}
\tag{K}
\]

也就是：

\[
\begin{array}{c}
(a,c),(b,d)\\
\text{交叉}
\end{array}
\quad\Longrightarrow\quad
\begin{cases}
(a,b),(c,d),&\text{分离},\\
(a,d),(b,c),&\text{嵌套},
\end{cases}
\]

两种消交都不会增大代价。

## 2. “隐藏弧稳定性”到底在说什么

在一个不交叉匹配中：

- 没有被其他边包含的边叫暴露弧；
- 被某条边严格包含的边叫隐藏弧。

例如

\[
(i,k),\qquad (i+1,p),\qquad i<i+1<p<k
\]

中，\((i,k)\) 是暴露弧，\((i+1,p)\) 是隐藏弧。

现在假设 \(M\) 是一个连续区间上的最优匹配，再在它左边或右边加入偶数个新点。隐藏弧稳定性说：

> 可以选取新的最优匹配，使原匹配的所有隐藏弧继续存在；只有最外层的暴露弧可能被重新连接。

证明思路是：假如某条隐藏弧被破坏，那么其内部必然有若干点被连到区间外。由于最终匹配不交叉，这些伸出去的边按嵌套次序排列。依次使用 (K) 的两种消交，把内部点重新两两连接、外部端点重新连接，就能恢复原来的隐藏部分，且总代价不增加。

弱不等号下不保证“所有最优解”都保持隐藏弧，但保证“可以选择一组彼此兼容的最优解”。这正是后面拼接需要的性质。论文中的完整版本是 [Theorem 5，二阶递推是 Theorem 6](https://arxiv.org/abs/1102.1558)。

## 3. 三个区间是怎样拼接的

记

\[
L=F_{i,j-2},\qquad
C=F_{i+2,j-2},\qquad
R=F_{i+2,j}.
\]

它们覆盖的点分别是

\[
\begin{aligned}
L &: [i,j-2],\\
C &: [i+2,j-2],\\
R &: [i+2,j].
\end{aligned}
\]

也就是说 \(C\) 是 \(L,R\) 的公共部分。

通过隐藏弧稳定性，可以把这三个最优匹配选得相互兼容：从 \(C\) 变到 \(L\)，只重新连接左侧暴露弧；从 \(C\) 变到 \(R\)，只重新连接右侧暴露弧。

在 \(L\) 中，设

\[
i\leftrightarrow k,\qquad i+1\leftrightarrow p.
\]

除去 \(i\leftrightarrow i+1\) 的退化情况，有

\[
i<i+1<p<k\le j-2.
\]

因此 \(L\) 可以拆成

\[
\begin{aligned}
F_{i,j-2}
={}&w(i,k)+w(i+1,p)\\
&+F_{i+2,p-1}
+F_{p+1,k-1}
+F_{k+1,j-2}.
\end{aligned}
\tag{1}
\]

类似地，在 \(R\) 中设

\[
q\leftrightarrow j,\qquad s\leftrightarrow j-1,
\]

其顺序为

\[
i+2\le q<s<j-1<j,
\]

于是

\[
\begin{aligned}
F_{i+2,j}
={}&F_{i+2,q-1}
+F_{q+1,s-1}
+F_{s+1,j-2}\\
&+w(q,j)+w(s,j-1).
\end{aligned}
\tag{2}
\]

现在只需要比较 \(k\) 与 \(q\)。

## 4. 情况一：\(k<q\)，两侧暴露弧没有相撞

此时结构是

```text
i  i+1 ... p ... k | ...... | q ... s ... j-1  j
└─────────────┘                 └────────────────┘
   └──────┘                        └──────────┘
```

左侧暴露弧 \((i,k)\) 与右侧暴露弧 \((q,j)\) 分离，因此能合法拼接。

公共最优匹配 \(C\) 可以在 \(k,q\) 处分成

\[
F_{i+2,j-2}
=
F_{i+2,k}
+F_{k+1,q-1}
+F_{q,j-2}.
\tag{3}
\]

同时，

\[
\begin{aligned}
F_{k+1,j-2}
&=F_{k+1,q-1}+F_{q,j-2},\\
F_{i+2,q-1}
&=F_{i+2,k}+F_{k+1,q-1}.
\end{aligned}
\tag{4}
\]

把 (3)(4) 代入

\[
L+R-C
\]

后，公共部分左右两段各被“加一次、减一次”而消掉，中间段留下恰好一次，得到

\[
\begin{aligned}
L+R-C
={}&w(i,k)+w(i+1,p)\\
&+F_{i+2,p-1}+F_{p+1,k-1}\\
&+F_{k+1,q-1}\\
&+w(q,j)+F_{q+1,s-1}\\
&+w(s,j-1)+F_{s+1,j-2}.
\end{aligned}
\tag{5}
\]

式 (5) 明确对应一个合法匹配：

- 左边沿用 \(L\)；
- 中间使用 \(F_{k+1,q-1}\)；
- 右边沿用 \(R\)。

所以这里的减法不是抽象容斥，而是真的在“左最优解 + 右最优解”中删除重复的公共匹配。

它的代价正是

\[
\boxed{
F_{i,j-2}+F_{i+2,j}-F_{i+2,j-2}.
}
\]

而且所有“不使用 \((i,j)\)”的不交叉匹配，左右端点必然属于两个分离的暴露弧，都是这种结构。因此它是这一类匹配的最小值。

## 5. 情况二：\(k>q\)，拼接会产生交叉

现在四个端点顺序为

\[
i<q<k<j.
\]

拼出来的两条边

\[
(i,k),\qquad(q,j)
\]

发生交叉：

```text
i ------ q ------ k ------ j
 \____________/
          \____________/
```

因此 \(L+R-C\) 此时不一定直接表示不交叉匹配。但利用题目中的不等式，

\[
w(i,j)+w(q,k)
\le
w(i,k)+w(q,j),
\]

可以将两条交叉边替换为

\[
(i,j),\qquad(q,k).
\]

替换后得到一个包含外层边 \((i,j)\) 的合法匹配，且代价不超过 \(L+R-C\)。

所有包含 \((i,j)\) 的匹配中，最小代价显然是

\[
w(i,j)+F_{i+1,j-1}.
\]

所以在 \(k>q\) 的情况下必有

\[
w(i,j)+F_{i+1,j-1}
\le
F_{i,j-2}+F_{i+2,j}-F_{i+2,j-2}.
\]

也就是说，第二项即使拼出了交叉，也必然被第一项压住。

\(k=q\) 不可能发生：非交叉完美匹配的每条边连接一奇一偶，而 \(k,q\) 的奇偶性相反。

## 6. 最终递推

于是所有最优匹配只有两个本质状态：

1. 左右暴露部分合并成外层弧 \((i,j)\)；
2. 左右暴露部分互不相撞，分别保留。

因此

\[
\boxed{
F_{i,j}
=
\min\left\{
w(i,j)+F_{i+1,j-1},\;
F_{i,j-2}+F_{i+2,j}-F_{i+2,j-2}
\right\}.
}
\]

第二项最直观的理解是：

\[
\underbrace{F_{i,j-2}}_{\text{加入左边两个点}}
+
\underbrace{F_{i+2,j}}_{\text{加入右边两个点}}
-
\underbrace{F_{i+2,j-2}}_{\text{公共中间部分只保留一次}}.
\]

但这个“容斥”成立的真正原因，是隐藏弧稳定性保证三个最优匹配能够选得相互兼容；对任意普通区间 DP，直接这样相减当然是不成立的。
