推一下式子

$$\begin{align*}
ans &= \sum_{i = 1}^{n} \sum_{j = 1}^{m} \frac{a_i b_j}{\gcd^2(a_i, b_j)} \\
    &= \sum_{i = 1}^{N} \sum_{j = 1}^{N} c_i d_j \frac{ij}{\gcd^2(i, j)} \\
    &= \sum_{g = 1}^{N} \sum_{i = 1}^{N} \sum_{j = 1}^{N} c_i d_j \frac{ij}{g^2} [\gcd(i,j) == g] \\
    &= \sum_{g = 1}^{N} \sum_{i = 1}^{\lfloor\frac{N}{g}\rfloor} i c_{ig} \sum_{j = 1}^{\lfloor\frac{N}{g}\rfloor} j d_{jg}  [\gcd(i,j) == 1] \\
    &= \sum_{g = 1}^{N} \sum_{k = 1} ^{\lfloor\frac{N}{g}\rfloor} \mu(k) \sum_{i = 1}^{\lfloor\frac{N}{kg}\rfloor} ik c_{ikg} \sum_{j = 1}^{\lfloor\frac{N}{kg}\rfloor} jk d_{jkg} \\
    &= \sum_{g = 1}^{N} \sum_{k = 1} ^{\lfloor\frac{N}{g}\rfloor} k^2 \mu(k) \sum_{i = 1}^{\lfloor\frac{N}{kg}\rfloor} i c_{ikg} \sum_{j = 1}^{\lfloor\frac{N}{kg}\rfloor} j d_{jkg} \\
    &= \sum_{T = 1}^{N} F(T) G(T) \sum_{k | T} k^2 \mu(k) \\
    &= \sum_{T = 1}^{N} F(T) G(T) H(T) \\
\end{align*}$$

对于 $F$, $G$
$$\begin{align*}
    F(T) = \sum_{i = 1}^{\lfloor\frac{N}{T}\rfloor} i c_{iT}
\end{align*}$$
利用Dirichlet后缀和可以这样实现：
```c++
// a = f or g
for(auto p : prime){
    for(int i = N / p;i >= 1;i--){
        a[i] = (a[i] + 1ll * p * a[p * i]) % P;
    }
}
```

对于 $H$
$$\begin{align*}
    H(T) = \sum_{k | T} k^2 \mu(k)
\end{align*}$$
可以直接$O(n)$筛
也可以利用Dirichlet前缀和这样实现：
```c++
// a = mu
for(int i = 1;i <= N;i++){
    a[i] = (1ll * a[i] * i * i % P + P) % P;
}
for(auto p : prime){
    for(int i = 1；i * p <= N;i++){
        a[i * p] = (a[i * p] + a[i]) % P;
    }
}
```
